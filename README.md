# Custom Media Player\n\nA highly polished, static-deployable media player mimicking the Spotify web player UI. Built with pure HTML5, CSS3, and Vanilla JavaScript.\n\n## Features\n- **Spotify Aesthetic**: Dark mode, exact color palettes, and full-screen layout.\n- **Custom Scrubber**: Uses `requestAnimationFrame` for buttery-smooth progress bar updates.\n- **Audio Controls**: Play, Pause, Next, Previous, and seeking functionality.\n
